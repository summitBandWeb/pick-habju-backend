## 1. 키워드 추출 실패 트러블슈팅

### 문제
Chama Studio(placeId=1217837723)의 네이버 대표 키워드 추출이 간헐적 실패하여 합주실 후보에서 탈락.

### 진단
- 3가지 시나리오(prod_headless/prod_headful/relaxed_headless) 모두 **성공** → 구조적 실패가 아닌 간헐적 실패
- 상세 페이지 Apollo State에 `informationTab.keywordList` 5개 키워드 존재 확인
- DOM 텍스트에서 키워드가 공백 없이 연결됨 (26자)

### 발견된 버그 & 수정

| # | 위치 | 문제 | 수정 |
|---|------|------|------|
| 1 | `_extract_representative_keywords_from_text()` | `len(token) > 20` 필터가 연결 키워드(26자) 탈락 | `> 60`으로 상향 |
| 2 | section break 감지 | 정확 일치(`line in set`)라 "편의시설 및 서비스1" 미감지 | `startswith` 매칭 + "SNS" 추가 |

### 추가 개선
- `_extract_keywords_from_frame()` 헬퍼 분리 → Apollo + DOM 추출 통합
- 빈 결과 시 `INFO_TAB_RENDER_WAIT_MS` + jitter 대기 후 1회 재시도
- **3중 방어**: Apollo State walk → DOM text fallback → 재시도

### 의사결정
- **Fix A(버그 수정) + Fix B(재시도) 둘 다 적용** — "2중 3중으로 점검해도 모자른게 개발" (경수님)

## 5. 시간대 중복 Room 분석 & 의사결정

### 발견
같은 물리적 방이 시간대별로 별도 room으로 존재 — 11그룹.

**예시 (비쥬 합주실 1호점 — 블랙룸)**:

| biz_item_id | name | price |
|---|---|---|
| 3968885 | 블랙룸 | 19,000원 (기본) |
| 7115653 | 블랙룸 (평일 낮) | 10,000원 |
| 7452675 | 블랙룸 (심야) | 15,000원 |

### 의사결정
- **A안 (병합)**: 기본 가격 room만 남기고 나머지를 `price_config.overrides`로 병합
- **B안 (현행 유지)**: 별도 room으로 관리

**결론: B안 (현행 유지)** — 병합하려면 네이버 예약 페이지에서 각 상품의 시간 범위를 크롤링해야 하는데, description이 비어있고 room name의 "심야", "평일 낮" 힌트만으로는 정확한 시간 범위를 알 수 없음. 구현 난이도 대비 효과가 불확실하여 보류.
